# Hack-Tools-Chinese
本目录是 HackTools 0.5.0 的简体中文汉化版本，功能与原版完全一致，仅界面文字改为中文。【汉化范围】 - 侧边栏全部工具名称、页面标题、按钮、输入框占位符、提示消息。 - 数据编码 / 哈希 / 文件传输 / 文件混淆 / Linux 命令 / PowerShell 命令 /   反弹 Shell / MSF Venom / TTY / LFI / XSS / SQL 注入 / PHP 反弹 Shell /   About（关于我们）/ RSS 订阅与 CVE 查询等页面的说明文字与栏目。 - 分页、筛选菜单、空数据提示、Markdown 编辑器工具栏提示等组件内置文案。
